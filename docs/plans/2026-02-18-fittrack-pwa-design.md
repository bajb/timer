# FitTrack — Personal Trainer PWA Design\n\n**Date:** 2026-02-18\n**Status:** Approved\n\n## Overview\n\nA mobile-first Progressive Web App for personal trainers to manage clients, track structured goals with metrics, log workout sessions, and run a configurable HIIT timer with audio/vibration cues. Scales to desktop with a sidebar layout for planning.\n\n## Tech Stack\n\n| Layer | Choice | Rationale |\n|-------|--------|-----------|\n| Framework | React 18 + TypeScript | Mature ecosystem, strong PWA tooling |\n| Build | Vite | Fast dev server, optimized builds |\n| Routing | React Router v6 | Client-side navigation, nested routes |\n| Data | Dexie.js (IndexedDB) | Local-first, typed, reactive hooks, Dexie Cloud upgrade path |\n| UI State | Zustand | Lightweight store for timer & ephemeral UI state |\n| Styling | Tailwind CSS | Utility-first, mobile-first responsive design |\n| PWA | vite-plugin-pwa | Service worker, manifest, installability |\n| Icons | Lucide React | Consistent, lightweight icon set |\n| IDs | uuid (v4) | Unique identifiers for all entities |\n\n## Data Model\n\n### Client\n\n| Field | Type | Notes |\n|-------|------|-------|\n| id | string (uuid) | Primary key |\n| name | string | Full name |\n| email | string? | Optional |\n| phone | string? | Optional |\n| notes | string? | General notes |\n| avatarColor | string | Auto-assigned color for UI |\n| createdAt | Date | |\n| updatedAt | Date | |\n\n### Goal\n\n| Field | Type | Notes |\n|-------|------|-------|\n| id | string (uuid) | Primary key |\n| clientId | string | FK to Client |\n| title | string | e.g. \"Lose 10kg\" |\n| metricType | enum | `weight`, `reps`, `time`, `distance`, `custom` |\n| metricUnit | string | e.g. \"kg\", \"reps\", \"seconds\", \"km\" |\n| startValue | number | Starting measurement |\n| targetValue | number | Target measurement |\n| deadline | Date? | Optional target date |\n| status | enum | `active`, `achieved`, `paused`, `abandoned` |\n| createdAt | Date | |\n\n### GoalCheckIn\n\n| Field | Type | Notes |\n|-------|------|-------|\n| id | string (uuid) | Primary key |\n| goalId | string | FK to Goal |\n| sessionId | string? | Optional FK to Session |\n| value | number | Current measurement |\n| note | string? | Optional note |\n| recordedAt | Date | |\n\n### Session\n\n| Field | Type | Notes |\n|-------|------|-------|\n| id | string (uuid) | Primary key |\n| clientId | string | FK to Client |\n| date | Date | Session date |\n| type | enum | `strength`, `cardio`, `hiit`, `flexibility`, `custom` |\n| notes | string? | Session notes |\n| exercises | Exercise[] | Inline array of exercises |\n| hiitConfig | HIITConfig? | If HIIT was used |\n| duration | number? | Total session duration in seconds |\n| createdAt | Date | |\n\n### Exercise (embedded in Session)\n\n| Field | Type | Notes |\n|-------|------|-------|\n| name | string | Exercise name |\n| sets | number? | |\n| reps | number? | |\n| weight | number? | |\n| duration | number? | In seconds |\n| notes | string? | |\n\n### HIITConfig (embedded in Session)\n\n| Field | Type | Notes |\n|-------|------|-------|\n| exerciseTime | number | Seconds |\n| restTime | number | Seconds |\n| rounds | number | Number of rounds |\n| completedRounds | number | How many were actually completed |\n\n## UI Structure & Navigation\n\n### Navigation\n\nMobile-first bottom tab bar with 4 tabs, collapsing to a sidebar on desktop:\n\n| Tab | Icon | View |\n|-----|------|------|\n| Clients | Users | Client list -> Client detail |\n| Sessions | Calendar | Today's sessions / session log |\n| Timer | Timer | Standalone HIIT timer |\n| Settings | Gear | Audio/vibration toggle, app info |\n\n### Screen Flow\n\n```\nClients Tab\n├── Client List (search, add button)\n├── Client Detail\n│   ├── Profile info (name, contact, notes)\n│   ├── Goals section (list of structured goals)\n│   │   ├── Add/Edit Goal (metric type, start/target value, deadline)\n│   │   └── Goal Detail (progress chart, check-in history)\n│   └── Sessions section (session history for this client)\n│       ├── Add/Edit Session (type, exercises, notes)\n│       └── Session Detail (view logged session)\n\nSessions Tab\n├── Session List (all sessions, filterable by date/client)\n└── Quick-add Session\n\nTimer Tab\n├── HIIT Config (exercise time, rest time, rounds)\n├── Timer Running (big countdown, round indicator, pause/stop)\n└── Timer Complete (summary, option to attach to a session)\n\nSettings Tab\n├── Audio toggle\n├── Vibration toggle\n└── About / data export\n```\n\n### Desktop Planning Mode (>=768px)\n\n- Left sidebar with client list (always visible)\n- Main content area showing client detail / session / goals\n- Timer opens as a slide-over panel rather than a full screen\n- Lets trainers plan sessions on a laptop with the client roster always visible\n\n### Responsive Breakpoints\n\n- `< 768px` — mobile layout (bottom tabs, full-screen views)\n- `>= 768px` — desktop layout (sidebar + main content, timer as overlay)\n\n## HIIT Timer Design\n\n### Configuration Screen\n\n- **Exercise Time** — stepper control (5s increments, default 30s, range 5s-300s)\n- **Rest Time** — stepper control (5s increments, default 15s, range 5s-300s)\n- **Rounds** — stepper control (1 increment, default 8, range 1-50)\n- **Total Time** display — auto-calculated: `(exerciseTime + restTime) * rounds`\n- **Preset buttons** — Tabata (20/10/8), Classic (40/20/10), Custom\n- **Start button**\n\n### Running Timer Screen\n\n- Full-screen takeover on mobile\n- Large countdown number (central, dominant)\n- Phase indicator — \"EXERCISE\" (green) or \"REST\" (red), large and visible\n- Round counter — \"Round 3 of 8\"\n- Progress ring — circular progress around the countdown\n- Controls — Pause/Resume, Stop (with confirmation)\n- Audio — 3-2-1 countdown beeps before phase transitions, long beep on round complete\n- Vibration — short pulse on phase transition, pattern on final round\n- Wake Lock — screen stays on during timer\n\n### Timer Complete Screen\n\n- Summary: rounds completed, total time\n- Attach to session button — auto-attach if started from session; option to link if standalone\n- Restart or Edit & Restart\n\n### Timer State (Zustand)\n\nTimer state is ephemeral UI state, not persisted:\n\n- `phase`: `idle` | `exercise` | `rest` | `complete`\n- `timeRemaining`: number (seconds)\n- `currentRound`: number\n- `config`: HIITConfig\n- `isPaused`: boolean\n- `audioEnabled`: boolean\n- `vibrationEnabled`: boolean\n\nUses `requestAnimationFrame` for accurate visual updates with `setInterval` fallback for background tab timing.\n\n## Project Structure\n\n```\n~/projects/trainer-app/\n├── public/\n│   └── icons/              # PWA icons (192, 512)\n├── src/\n│   ├── main.tsx cache for any future API calls\n- **Install prompt:** custom banner on first few visits\n\n## Key UI Patterns\n\n- **Mobile:** Full-screen views with back navigation, bottom tabs\n- **Desktop:** Sidebar + main content, timer as overlay panel\n- **Forms:** Slide-up sheets on mobile, inline panels on desktop\n- **HIIT Timer:** Full-screen takeover on mobile with large numbers, keeps screen awake via Wake Lock API\n\n## Data Storage\n\n- All data stored locally in IndexedDB via Dexie.js\n- Works fully offline after first load\n- Optional sync can be added later via Dexie Cloud (paid add-on)\n- Settings (audio/vibration toggles) stored in localStorage\n
